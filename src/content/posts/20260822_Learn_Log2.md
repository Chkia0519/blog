## 第一步 - 建立 `log_monitor.py` 做即時監控

　　在資料夾中新增一個`log_monitor.py`

　　寫入程式碼：
```Python
import time

with open("system.log", "r", encoding="utf-8") as file:
    logs = file.readlines()

processed_count = len(logs)

print("開始監控 system.log")

try: 
    while True:
        with open("system.log", "r", encoding="utf-8") as file:
            current_logs = file.readlines()
    
        if len(current_logs) > processed_count:
            new_logs = current_logs[processed_count:]
    
            for log in new_logs:
                if "CRITICAL" in log:
                    print(f"[嚴重異常] {log.strip()}")
    
                elif "ERROR" in log:
                    print(f"[異常] {log.strip()}")
    
                elif "WARNING" in log:
                    print(f"[警告] {log.strip()}")
    
            processed_count = len(current_logs)
    
        time.sleep(3)
    
except KeyboardInterrupt:
    print("\n監控已停止")
```

　　`processed_count = len(logs)`記錄程式開始時已經有幾筆 Log，也就是目前已看過幾筆 Log

　　然後使用`while True:`來做無限監控 Log

　　`if len(current_logs) > processed_count:`拿來判斷是否有新的 Log 出現

　　如果有的話就`new_logs = current_logs[processed_count:]`用串列切片，從索引`processed_count`開始，取得後面所有資料

　　用for迴圈`for log in new_logs:`來逐筆檢查新增的 Log

　　處理完之後用`processed_count = len(current_logs)`更新目前已經處理到的 Log 數量

　　最後使用`time.sleep(3)`暫停3秒之後再進入下一次 while 迴圈

　　加上 try / except ，`KeyboardInterrupt`的意思是**使用者主動中斷程式**，這樣子停止時就不會跳出一長串錯誤訊息

### 第二步 - 監控期間如果 Log 檔案突然不見，怎麼辦?

　　這時候就要再派出 try / except 了

　　修改後如下：

```Python
        try:
            with open(LOG_FILE, "r", encoding="utf-8") as file:
                current_logs = file.readlines()

        except FileNotFoundError:
            print("找不到 system.log，等待 Log 檔案恢復...")
            time.sleep(3)
            continue
```

　　因為加上了`continue`，所以迴圈不會中止，只會跳過這一次

　　如果是用`break`的話就會直接中止迴圈

### 第三步 - 把會修改到的設定集中到程式最上面

　　像是.log的檔名或是時間的間隔，都可以用變數來取代

　　這樣如果我今天想要更改監控的 Log ，我就可以直接從變數改就好

　　在程式碼最上方新增：

```Python
LOG_FILE = "system.log" #放檔案名稱的
CHECK_INTERVAL = 3 #調整時間間隔
```

　　且將欄位更動為變數，這樣就完成優化了

---

### 第四步 - 優化程式碼

　　因為一直出現重複地打開檔案的動作

　　這時候就可以用`def`函數把重複執行的程式碼包起來，可以減少過多程式碼，也可以更好閱讀

　　建立函式後的程式碼 :

```Python
def read_logs():
    with open(LOG_FILE, "r", encoding="utf-8") as file:
        return file.readlines()
```

　　def -> 定義函式

　　read_logs() ->自己命名的函式，用來讀取 Log

　　return -> 將函式處理後的結果傳回去

### 第五步 - 增加防呆功能，如何處理 Log 被清空或重新建立的情況

　　實務上蠻常出現 Log 檔案可能會被清空或重新建立的狀況，這時候就會需要加上一些防呆的程式碼

　　在判斷資料的程式碼前加入一段：

```Python
if len(current_logs) < processed_count:
    processed_count = 0
```
　　意思是，如果現在的程式碼比之前紀錄的少，那就從0開始算
