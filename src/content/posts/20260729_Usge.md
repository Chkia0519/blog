## 多行程式碼

在程式碼的最前方跟最後方加上```即可

可以在第一行的```後方可以寫上使用的程式語言為何

如果要做像是底下範例，最外層可以變成````

範例:

````
  ```bash <-語言
  git add .
  git commit -m "first post"
  git push
  ```
````

效果:

```bash 
git add .
git commit -m "first post"
git push
```

## 清單

### 無序號

範例:

```
 - 第一項
 - 第二項
 - 第三項
```

效果:

 - 第一項
 - 第二項
 - 第三項

### 有序號

範例:

```
 1. 第一項
 2. 第二項
 3. 第三項
```

效果:

 1. 第一項
 2. 第二項
 3. 第三項

要加入
import { Image } from "astro:assets";
import 變數 from "@/assets/images/檔名.JPG";

用底下這個格式就可以放圖片了
<Image
  src={變數} -> 我import時候面的變數名稱
  alt="Pocky"/> ->圖片的替代名稱
```
