上一篇有提到，可以用 `git status` 查看目前的狀態

當已經開始建立版本控制時，要查看過去的歷史就要用 `git log`

這一篇是在講怎麼用 `git status` 查看目前的狀態

---

## 直接在 CMD 中輸入 `git status`

　　不會修改任何資料，只會查看目前的狀態

- ### 狀況1：出現`Untracked files`

　　`Untracked files` -> 代表這是新檔案，Git 還尚未追蹤

- ### 狀況2：出現`modified`

　　`modified` -> 代表這是舊檔案，已經commit過了，但這次有修改這個檔案，還沒加入暫存區

- ### 狀況3：已經執行 `git add`

```
Changes to be committed:

    modified: 檔案
```

　　Changes to be committed -> 檔案已經存在暫存區了，可以進行commit了

- ### 狀況4：事情已經都執行完畢

　　`nothing to commit, working tree clean`

　　代表所有事情都做好了，目前沒有尚未 commit 的修改，也沒有東西放在暫存區
