`git revert <Commit ID>` 

會根據指定 Commit 的修改內容，自動建立一個新的反向 Commit，用來抵消該 Commit 的效果

意思就是 Git 會將指定 Commit 的新增、刪除等操作反向執行，並建立一個新的 Commit

不會刪除原本的 Commit，而是透過新增一個反向 Commit 來抵消指定 Commit 的效果

例如：

```text
Commit C：

+ Hello
```

執行：

```bash
git revert C
```

Git 會建立新的 Commit：

```text
- Hello
```

因此：

```text
Commit C：新增 Hello
Revert Commit：移除 Hello
```

兩者的效果互相抵消。
