`git clone <Git Repository_URL>`

`git clone` 的概念是 **複製任何 Git Repository(Git 儲存庫)**

`git clone`複製了Repo後會：

預設會自動建立一個名稱為 origin 的遠端連線，記住這個 Repo 是從哪裡 Clone 下來的

所以如果今天只是普通資料夾，並沒有 .git 檔案就無法進行 `git clone`

可以先在該資料夾目錄執行 `git status`，來確認是否為Git 儲存庫

如果真的想要 clone 該資料夾，可以cd到該資料夾做 `git init`、`git add .`、`git commit`

---

### 常見儲存庫

1. GitHub
2. GitLab
3. Bitbucket - Atlassian 公司（Jira 開發商）推出的 Git 平台)
4. Azure DevOps - 微軟提供的企業級 DevOps 平台
5. Gitea - 輕量級 Git 伺服器，很多公司會自行架設
6. 自架 Git Server - 公司內部有 Git Server，就能 Clone
7. 本機資料夾 - 該資料夾必須要是 Git Repository 才可以複製，檢查有沒有.git目錄
8. 網路磁碟或共享資料夾 - 一樣要是 Git Repository 才可以複製

---

### `git clone` 和下載 ZIP 的差別

1. 下載 ZIP 下載下來的是**目前版本的專案檔案**

不會包含`.git`，所以這個資料夾本身不是 Git Repo

也代表我無法使用`git log`來看歷史，因為他沒有一起下載 Git 歷史紀錄(.git)

2. `git clone`除了目前的專案檔案，也會一起取得 Git Repo 的資料

因此 Clone 完之後可以直接使用`git log`來看歷史，也可以用很多git的程式碼

用`git remote -v`，可以查看這個 Repo 是從哪裡 Clone 下來的

---

### `git clone` 執行後，Git 會自動做哪些事情

1. 建立新的資料夾
2. 把 Repo 的資料抓到本機
3. 自動建立 origin
4. 自動切換到預設分支
5. 建立遠端追蹤關係 -> 可以直接使用pull或是push

---

>[!TIP] 
>執行`git clone`後，終端機**不會**自動cd到該資料夾
>
>所以要記得手動進到該資料夾，才可做後續指令

---

## 日常用指令

---

### 指定 clone 後的資料夾名稱

`git clone <Git Repo_URL> <新名稱>`

例如：`git clone https://github.com/user/project.git myproject`

原本名稱會是 project，現在後面加上了新名稱，所以新資料夾名稱會是 myproject

---

### Clone 指定 Branch 

`git clone -b <branch> <Git Repo_URL>`

假設這個 Repo 有多個分支

我 Clone 的時候想指定到某個分支就可以使用這個指令

例如：`git clone -b test https://github.com/user/project.git`

預設分支是main，這次用了這個指令代表我們 Clone 下來的時候就會在 test 這個分支了

---

其實還有很多指令，但是比較不常用

有遇到再去查怎麼使用就好

```
git clone -b
git clone --depth
git clone --single-branch
git clone --bare
git clone --mirror
git clone --recurse-submodules
```

像是上面這些都比較不算日常會用到的，到時候再查就好

---

### clone 速查表

| 指令 | 用途 |
|------|------|
| `git clone 網址` | 複製 Repo |
| `git clone -b develop 網址` | Clone 指定分支 |
| `git clone --depth 1 網址` | 只下載最新版本 |
| `git clone --single-branch 網址` | 只下載單一分支資訊 |
| `git clone --bare 網址` | 建立裸倉庫 |
| `git clone --mirror 網址` | 建立鏡像倉庫 |
| `git clone --recurse-submodules 網址` | 同步下載 Submodule |
| `git clone --no-checkout 網址` | 不自動展開檔案 |
| `git clone --filter=blob:none --sparse 網址` | 部分下載大型專案 |
