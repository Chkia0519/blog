`git clone <Git Repository_URL>`

`git clone` 的概念是 **複製任何 Git Repository(Git 儲存庫)**

所以如果今天只是普通資料夾，並沒有 .git 檔案就無法進行 `git clone`

可以先在該資料夾目錄執行 `git status`，來確認是否為Git 儲存庫

如果真的想要 clone 該資料夾，可以cd到該資料夾做 `git init`

#### 常見儲存庫

1. GitHub
2. GitLab
3. Bitbucket - Atlassian 公司（Jira 開發商）推出的 Git 平台)
4. Azure DevOps - 微軟提供的企業級 DevOps 平台
5. Gitea - 輕量級 Git 伺服器，很多公司會自行架設
6. 自架 Git Server - 公司內部有 Git Server，就能 Clone
7. 本機資料夾 - 該資料夾必須要是 Git Repository 才可以複製，檢查有沒有.git目錄
8. 網路磁碟或共享資料夾 - 一樣要是 Git Repository 才可以複製

---

### 指定clone後的資料夾名稱

`git clone <Git Repository_URL> <新名稱>`

例如：`git clone https://github.com/user/project.git myproject`

原本名稱會是 project，現在後面加上了新名稱，所以新資料夾名稱會是 myproject
