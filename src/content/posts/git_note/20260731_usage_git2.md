### 第一次設置

繼前篇安裝好Git之後，需要做第一次的設置

因為Git是分散式的版本控制系統，所以每一台機器都需要設定 名字和Email 

設置Git的程式碼如下:

```

$ git config --global user.name " 名字 "
$ git config --global user.email " Email "

```
> [!IMPORTANT]
> `git config` 指令的 `--global` 參數，用了他等於這台機器所有的Git倉庫都會用這個名字與Email

--global 就是 **全域設定** 的意思


---

### 解除使用者設定 2026/08/21補

解除所有的設定：

`git config --global --unset user.name`

`git config --global --unset user.email`

`--unset` 的意思就是**解除設定**

如果只是要更換使用者，可以再次使用前面敘述到的設置 [Git 程式碼](http://localhost:4321/blog/posts/git_note/20260731_usage_git2/#%E7%AC%AC%E4%B8%80%E6%AC%A1%E8%A8%AD%E7%BD%AE)再設置一次名字和信箱

會直接將原本的使用者覆蓋掉

如果只是要解除當前專案的話，則不需要在程式碼裡加上`--global`
