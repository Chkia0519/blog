設置完帳號之後，接下來就是創立倉庫

可以用下指令的方式來創立一個新資料夾，然後將這個專案資料夾變成Git倉庫

也可以用右鍵新增資料夾，然後cd至資料夾下指令變成Git倉庫

在cmd下創立資料夾下指令的範例：

```bash
mkdir learngit
cd learngit
```
mkdir -> 創立一個新資料夾

cd -> 移動

---

建議先在`git init`前做`git config --global init.defaultBranch main`

意思是之後新建倉庫分支名稱會是main，就不需要每次都執行`git branch -M main`

因為Git預設分支名稱是master，但Github預設是main，所以改成main比較不會混亂

cd到要設置Git倉庫的資料夾，輸入 `git init`後，這個資料夾就會變成Git可以管理的倉庫了

目前這一步只是將資料夾變成倉庫，但還沒有存資料進去

會在此資料夾中多一個名字為 .git 的隱藏資料夾，這個資料夾裡面存放的資料就是Git儲存版本歷史、分支、設定等資料的地方



> [!TIP]
> `git init` 只是讓 Git 知道從現在開始管理這個資料夾，但還沒真正開始建立版本

> [!WARNING]
>**只有第一次需要`git init`，不需要每次都打，因為`.git`已存在，所以不用再打第二次**
