remote 是什麼？

Git Repo 可以存在兩個地方：

1. 本機 Repo
2. 遠端 Repo

Git 需要記得目前的本機 Repo 是對哪個遠端 Repo

那 remote 就是紀錄遠端 Repo 連線資訊的方式

origin 是遠端 Repo 的名稱

例如：

origin -> https://github.com/user/project.git

因為每次都輸入完整網址太長，所以可以幫遠端 Repo 取一個簡稱

那最常見的名稱就是 origin

所以 origin = 存著遠端 Repo 網址的名稱

---

1. 最基本的查看方式

查看目前設定了哪些遠端名稱 -> `git remote`

查看目前設定了哪些遠端名稱 + 網址 -> `git remote -v`

---

2. 新增遠端 Repo


git remote add <遠端名稱> <遠端Repository網址>
