remote 是什麼？

Git Repo 可以存在兩個地方：

1. 本機 Repo
2. 遠端 Repo

Git 需要記得目前的本機 Repo 是對哪個遠端 Repo

那 remote 就是紀錄遠端 Repo 連線資訊的方式

origin 是遠端 Repo 的名稱

例如：

origin -> https://github.com/user/project.git

因為每次都輸入完整網址太長，所以可以幫遠端 Repo 取一個簡稱

那最常見的名稱就是 origin

所以 origin = 存著遠端 Repo 網址的名稱

---

1. 最基本的查看方式

查看目前設定了哪些遠端名稱 -> `git remote`

查看目前設定了哪些遠端名稱 + 網址 -> `git remote -v`

---

2. 新增遠端 Repo - add


`git remote add <遠端名稱> <遠端Repository網址>`

git remote add = 新增一個遠端 Repo 設定

origin = 幫這個遠端 Repo 取的名稱

https://github.com/user/project.git = 遠端 Repo 的網址

假如今天在本機新建立 Repo，會先使用 `git init`

如果之後想讓這個本機 Repo 連到 GitHub 等遠端 Repo 就需要使用：

`git remote add origin <遠端Repository網址>`

但如果今天是用 `git clone` 的方式

因為 Clone 時通常已經自動建立 origin，所以就不需要再執行一次

---

3. 刪除遠端 Repo - remove

`git remote remove <遠端名稱>`

假如今天 origin -> https://github.com/user/project.git

但我發現我遠端 Repo 設定錯誤

就可以用`git remote remove origin`將 origin 這個遠端名稱刪除

>[!TIP]
>這個指令是把本機儲存的遠端連線設定刪掉，不是刪除遠端的 Repo 喔

---

4. 修改遠端 Repo 網址 - set-url

`git remote set-url <遠端名稱> <新的Repo網址>`

如果 origin 已經存在，但網址設錯了，就可以用這個指令來異動網址

執行後，可以用`git remote -v`來確認目前 origin 指向哪個網址

---

5. 修改遠端名稱 - rename

`git remote rename <舊名稱> <新名稱>`

例如我今天 origin 要改成 main：

`git remote rename origin main`

就是很好理解的更名指令(?)

---

6. 查看某個遠端名稱的網址 - get-url

`git remote get-url <遠端名稱>`

執行後只會出現目前指向的網址，不會有其他資訊

---

### 速查表

| 指令 | 用途 |
|------|------|
| `git remote` | 查看遠端名稱 |
| `git remote -v` | 查看遠端名稱＋網址 |
| `git remote add <遠端名稱> <Repo網址>` | 新增一個遠端 Repo 設定 |
| `git remote add origin <Repo網址>` | 建立名為 origin 的遠端 Repo |
| `git remote remove <遠端名稱>` | 刪除本機的遠端連線設定 |
| `git remote set-url <遠端名稱> <新網址>` | 修改遠端網址 |
| `git remote rename <舊名稱> <新名稱>` | 修改遠端名稱 |
| `git remote get-url <遠端名稱>` | 查看目前指向的遠端網址 |
