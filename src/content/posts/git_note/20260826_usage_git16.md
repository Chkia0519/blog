### Git 的暫時置物櫃 - `git stash`

　　執行`git stash`可以將目前工作目錄中尚未Commit的修改內容暫時存放到Stash中

　　大部分狀況是不用指定檔案，預設會將目前**已被 Git 追蹤，且尚未 Commit 的修改**一起存入Stash

　　新建立且仍為 `Untracked` 的檔案，預設不會一起 `stash`

　　很容易和[`git add`](/blog/posts/git_note/20260802_usage_git4/#2-%E5%8A%A0%E5%85%A5%E6%9A%AB%E5%AD%98%E5%8D%80---git-add)搞混，但兩種的用途並不相同

>[!TIP]
> `git add` 將修改內容放到暫存區，準備等待Commit
>
> `git stash` 將目前尚未Commit的修改內容放到`stash`中，並將工作目錄恢復成`HEAD`的狀態

---

### 查看 Stash 清單 - `git stash list`

　　既然我們已經把東西放到Stash裡面，接下來就是要怎麼查放進去哪些資料

　　這時候就可以執行`git stash list`

　　範例：

```

stash@{0}: WIP on main: a1b2c3d 修改首頁
stash@{1}: WIP on main: b2c3d4e 建立登入頁
stash@{2}: WIP on main: c3d4e5f 初始化專案

```

- `stash@{0}` -> Stash 的編號

　　最新存進去的就是`stash@{0}`，編號會以 新 -> 舊

　　執行`git stash`後，list裡面的原本的編號就會全部往後推

- `WIP on main` -> 意思是這是從main分支暫存下來、尚未完成的工作

　　WIP = Work In Progress = 進行中的工作

- `a1b2c3d 修改首頁` -> 當時HEAD指向的Commit ID&訊息

　　一句話解釋:

　　我在 main 分支上工作，當時HEAD位於 Commit `a1b2c3d 修改首頁` 時，把尚未完成的修改存進了stash

---

### 取回Stash，並移除紀錄 - `git stash pop`

　　會將最新一筆，也就是`stash@{0}`裡面的修改內容，重新套用到目前工作目錄

　　修改內容回到工作目錄後，這筆Stash也會從清單中**移除**

　　若沒有指定Stash，預設會取出最新的`stash@{0}`

　　也可以指定編號，例如`git stash pop stash@{1}`，取出特定的一筆Stash，並**移除**list中的紀錄 

---

### 取回Stash，但保留紀錄 - `git stash apply`

　　執行`git stash apply`會將Stash裡面的修改內容，重新套用到目前工作目錄

　　修改內容回到工作目錄後，這筆Stash會**保留**在清單中

　　若沒有指定Stash，預設會取出最新的`stash@{0}`

　　也可以指定編號，例如`git stash pop stash@{1}`，取出特定的一筆Stash，並**保留**list中的紀錄 


>[!TIP]
>`git stash pop` -> 套用Stash，但**移除**該筆Stash
>
>`git stash apply` -> 套用Stash，但**保留**該筆Stash

---

### 刪除指定的Stash紀錄 - `git stash drop`

　　執行`git stash drop`會刪除Stash list裡面紀錄的修改內容，且不套用到目前工作目錄

　　反正就是不會還原到工作目錄，直接刪掉紀錄

　　若沒有指定Stash，預設會刪除最新的`stash@{0}`

　　也可以指定編號，例如`git stash drop stash@{1}`，刪除特定的一筆Stash

---

### 刪除Stash的所有紀錄 - `git stash clear`

　　執行`git stash clear`會刪除Stash list裡面所有紀錄

　　**請謹慎使用**

　　在執行之前，建議先用`git stash list`查看是否都不需要了喔

---

### 統整表格

| 程式碼 | 用途 |
|------|------|
|`git stash`| 將目前工作目錄的修改存到Stash裡，並將工作目錄恢復成HEAD時的狀態 |
|`git stash list`| 查看Stash裡存的所有紀錄 |
|`git stash pop`| 取回最新（或指定）的Stash，並成功套用至工作目錄後**移除**紀錄 |
|`git stash apply`| 取回最新（或指定）的Stash，但**保留**紀錄 |
|`git stash drop`| 刪除Stash裡的指定紀錄 |
|`git stash clear`| 清空Stash裡的紀錄 |
