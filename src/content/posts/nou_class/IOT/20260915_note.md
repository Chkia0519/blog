## 第一部分

---

### 甚麼是互聯網 + 

**互聯網 +** 是互聯網發展的新型態或新業態，可以帶來很多新商機

本質是傳統產業的線上化、數據化、資訊化、自動化並進 -> 智慧化

以互聯網為基礎，將其融入各個產業及領域中

提高生產力和創新力的全新商業模式

以人為中心，透過互聯網可以串連不同產業，形成各種服務模式

---

### 有哪些互聯網 + ：

1. #### 互聯網 + 支付 -> 智慧金融新時代

銀行 <- 互聯網平台 -> LinePay(之類的Pay)

|功能|行為|
|------|------|
|行動支付|透過手機完成交易|
|數據收集|記錄消費時間、地點與內容|
|數據分析|分析消費模式與偏好|
|智慧推薦|提供個人化服務與建議|

>[!TIP]
>行動支付平台除了提供支付功能外，也能蒐集與分析消費數據，進一步提供個人化金融服務

2. #### 互聯網 + 物件 -> 物聯網的智慧生活

醫院、家人、超市 <- 互聯網平台 -> 智能手環、冰箱、藥盒

- 透過網路將各種智慧設備連接起來
- 設備會自動蒐集、傳送與交換資料
- 且會根據收集到的資訊提供更便利、更智慧的服務

例如：

- 智慧手環：監測心率、步數，並同步給手機或醫院
- 智慧冰箱：監控食材存量，提醒補貨
- 智慧藥盒：提醒使用者按時服藥，並且通知家人

>[!TIP]
>透過網路連接智慧物件，讓設備彼此交換資料，進而打造更智慧的生活

3. 互聯網 + 朋友 -> 社群網絡




4. 互聯網 + 設備 -> 工業4.0智慧製造
