`git log` -> 用來瀏覽**多筆** Commit 的歷史紀錄

`git show` -> 用來查看**單一** Commit 的詳細資料與修改內容

---

### 查看目前 Commit 的詳細內容 - `git show`

　　`git show` 預設只顯示一筆 Commit，如果沒指定Commit ID的話，就是目前 HEAD 指向的這筆 Commit

　　其中最重要的是，它**會顯示這筆 Commit 相較於前一筆 Commit 改了什麼**

例如：

```
A → B → C
        ↑
      HEAD (目前的 Commit)
```

　　所以當我執行 `git show` ，等於我是在查看 Commit C 的詳細內容，以及 C 相較於 B 修改了什麼

　　因為是查詢**一筆資料**，所以不用常常像 log 一樣要按 q 離開

　　但如果輸出內容超過終端機畫面，Git 可能會使用分頁檢視器顯示，此時可以按 q 離開

---

### 查看指定 Commit 中所有檔案詳細修改內容 - `git show <Commit ID>`

　　先用`git log --oneline`列出簡易歷史，找到想查詢的 Commit ID

　　找到之後執行`git show <Commit ID>` ，就會顯示它相較於前一筆 Commit 修改了哪些內容

#### 查看某筆 Commit 中**指定檔案**的修改內容 - `git show <Commit ID> -- <檔案路徑>`

　　如果沒有cd到檔案目前的位置就需要打出相對路徑

　　沒有加上檔案路徑就是 show 出 Commit 中**所有**檔案的修改內容 

　　加上檔案路徑就是只看這個 Commit 中**指定**檔案的修改內容 

　　`<Commit ID> -- <檔案路徑>` 其中 `--` 是用來分隔的，中間一定要有空格

　　`要查看的 Commit -- 要篩選的檔案路徑`

>[!TIP]
> `git show <Commit ID>` -> 指定 Commit 與前一個 Commit 的**全部**差異
>
> `git show <Commit ID> -- <檔案路徑>` -> 指定 Commit 與前一個 Commit 中，**指定**檔案的差異

---

### 查看某個 Commit 當時指定檔案的完整內容

　　`git show <Commit ID>:<檔案路徑>`

　　這邊的檔案路徑是從 Git 專案根目錄開始，跟我有無cd至所在資料夾無關

　　例如：`git show a1b2c3d:src/app.py`

　　意思就是：查看 a1b2c3d 這筆 Commit 當時，src/app.py 的完整內容

　　**不會顯示前後版本比較**

　　`<Commit ID>:<檔案路徑>` 其中 `:` 是用來選擇檔案的，中間不可以有空格


#### `<Commit ID> -- <檔案路徑>` 和 `<Commit ID>:<檔案路徑>`差異比較

| 比較項目 | `<Commit ID> -- <檔案路徑>` | `<Commit ID>:<檔案路徑>` |
|------|------|------|
| 用途 | 查看指定檔案在該 Commit 中的修改差異 | 查看該 Commit 當時，指定檔案的完整內容 |
| 是否顯示前後版本對比 | 是 | 否 |
| 顯示內容 | 該 Commit 對指定檔案做了哪些修改 | 該 Commit 當時特定檔案的完整內容 |
| 路徑基準 | 通常以目前所在目錄為基準 | 固定以 Git 專案根目錄為基準 |
| 符號作用 | `--` 是分隔 Commit 與檔案路徑 | `:` 是指定 Commit 裡面的檔案 |

### 查看 HEAD 前一筆 Commit 的詳細內容 - `git show HEAD~1`

　　例如：

```
A → B → C
        ↑
      HEAD (目前的 Commit)
```

　　執行`git show HEAD~1`，`HEAD~1`代表 HEAD 的前一筆

　　也就是 Commit B ，一樣會顯示 B 和 A 的比較

　　`git show` 會顯示「指定 Commit」與「它的上一筆 Commit」之間的差異

---

### 查看目前 Commit 修改了哪些檔案和行數統計 - `git show --stat`

　　`git show --stat`就是查看目前這筆 Commit 修改了哪些檔案，以及新增、刪除了多少行

　　跟`git log --stat`不一樣的地方一樣是 show 只會查看單筆， log 則是多筆

　　也可以查看指定 Commit 的修改統計，只要加入 Commit ID 即可

　　範例：`git show --stat <Commit ID>`

---

### 查看目前 Commit 修改了哪些檔案

　　`git show --name-only`

　　`--name-only` = 只列出檔案名稱

　　所以不會顯示行數統計，只會顯示改了那些檔案的檔案名稱

---

### 查看目前 Commit 修改過哪些檔案，並顯示每個檔案的變動狀態 

　　`git show --name-status`

　　查詢出來在檔案的前面的英文字母就代表檔案狀態：

　　A = Added 新增檔案

　　M = Modified 修改檔案

　　D = Deleted 刪除檔案

　　R = Renamed 重新命名檔案　

---

### 只顯示目前 Commit 的基本資料，不顯示檔案的修改差異

　　`git show --no-patch`

　　`--no-patch` = 不顯示修改差異的意思

　　他只會顯示：
```
commit 7480834d6a9e2bb5177340a0009184c49d5a0796 (HEAD -> main, origin/main, origin/HEAD)
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Tue Aug 11 17:59:11 2026 +0800

    show 第一篇
```

　　不會出現：

```
-title: Git 學習筆記 - 查看指定 Commit
+title: Git 學習筆記 - 查看指定 Commit
```

　　`git show --no-patch --oneline` 

　　只用一行顯示目前 Commit 的編號和提交訊息，不顯示修改內容

　　拿上面的當作範例，會顯示成：`748083 show 第一篇`

　　也可以在最後加入 Commit ID，查詢指定資料

>[!TIP]
> `git show --no-patch `-> 只看 Commit 的基本資料
> 
> `git show --no-patch --oneline` -> 將基本資料再精簡成一行

---

### 適合查看文章或 Markdown 修改 - `git show --word-diff`

　　一般用`git show`會以**一整行**來顯示跟前一筆 Commit 的差異

　　像是：

```
-title: Git 學習筆記 - 查看指定 Commit
+title: Git 學習筆記 - 查看指定 Commit
```

　　使用`git show --word-diff`，會改成以**文字或單字**來標示差異

　　例如：
```bash
`git [-show`-]{+log`+} -> [-用來查看**單一**-]{+用來查看**很多**+} Commit [-的詳細內容-]{+的歷史內容+}
```

　　很明顯能看出`{+文字+}`是新增，`[-文字-]`是刪除

　　非常適合用於查看文件類型的檔案

　　可在最後加上指定的 Commit id ，不然預設是 HEAD 喔

> [!TIP]
> 沒有指定 Commit -> 查看 HEAD 與前一筆 Commit 的文字差異
>
> 指定 Commit ->查看指定 Commit 與它前一筆 Commit 的文字差異
