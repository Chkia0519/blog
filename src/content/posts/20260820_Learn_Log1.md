## 第一步 - 記錄 Log

先建立一個資料夾：log_monitor

裡面再建立一個 `main.py`

範例程式碼：

```Python
import logging #安裝模組

logging.basicConfig(
    filename="system.log",  #設定log要存在哪
    level=logging.INFO,  #從哪個等級開始設定
    format="%(asctime)s - %(levelname)s - %(message)s",  #格式化字串
    # %(asctime)s : Log 發生時間   %(levelname)s : Log 等級  %(message)s : 我自訂義的訊息
    encoding="utf-8") #編碼

logging.info("系統啟動")
logging.info("使用者登入成功")
logging.warning("API 回應速度過慢")
logging.error("資料庫連線失敗")

print("Log 建立完成")
```
`logging.basicConfig()`：

是 logging 模組的基本設定，在同一個 Python 執行程序裡，通常只有**第一次設定**會生效

如果要重新設定，可以加上`force=True`，意思是不管之前有沒有設定過，都重新套用我目前這個設定

`filename="檔案名稱.log"`：設定 Log 要存在哪，副檔名是`.log`

`level=logging.INFO`：Log 要從哪個等級開始設定

等級如下：

| 等級 | 定義 |
|------|------|
| DEBUG | 開發人員除錯資訊 | 
| INFO | 正常運作資訊 | 
| WARNING | 有異常，但還能繼續 | 
| ERROR | 發生錯誤，部分功能失敗 | 
| CRITICAL | 嚴重錯誤，可能整個系統無法運作 | 


`format="%(asctime)s - %(levelname)s - %(message)s"`：格式化字串

- %(asctime)s : Log 發生時間  

- %(levelname)s : Log 等級

- %(message)s : 我自訂義的訊息

`encoding="utf-8"`：編碼

---

當我執行這個程式的時候，資料夾就會多出一個`system.log`的檔案

裡面會有這些資訊：

```
2026-08-20 22:14:25,893 - INFO - 系統啟動
2026-08-20 22:14:25,894 - INFO - 使用者登入成功
2026-08-20 22:14:25,894 - WARNING - API 回應速度過慢
2026-08-20 22:14:25,894 - ERROR - 資料庫連線失敗

```

將系統事件分級為如下：

- INFO：正常資訊

　　例如：登入成功、資料載入完成、系統啟動

- WARNING：有點異常，但系統還能繼續跑

　　例如：API回應過慢、記憶體使用率偏高、資料缺少部分欄位

- ERROR：發生錯誤

　　例如：資料庫連線失敗、檔案讀取失敗、API呼叫失敗

## 第二步 - 分析 Log

同一個資料夾裡，再建立一個新檔案`log_analyzer.py`

這個檔案是用來**自動讀取 Log，抓出 ERROR**

範例程式碼：

```Python
with open("system.log", "r", encoding="utf-8") as file:
    logs = file.readlines()

for log in logs:
    if "ERROR" in log:
        print(log.strip())
```
