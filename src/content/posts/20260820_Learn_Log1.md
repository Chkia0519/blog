## 第一步 - 記錄 Log

先建立一個資料夾：log_monitor

裡面再建立一個 `main.py`

範例程式碼：

```Python
import logging #安裝模組

logging.basicConfig(
    filename="system.log",  #設定log要存在哪
    level=logging.INFO,  #從哪個等級開始設定
    format="%(asctime)s - %(levelname)s - %(message)s",  #格式化字串
    # %(asctime)s : Log 發生時間   %(levelname)s : Log 等級  %(message)s : 我自訂義的訊息
    encoding="utf-8") #編碼

logging.info("系統啟動")
logging.info("使用者登入成功")
logging.warning("API 回應速度過慢")
logging.error("資料庫連線失敗")

print("Log 建立完成")
```
`logging.basicConfig()`：

是 logging 模組的基本設定，在同一個 Python 執行程序裡，通常只有**第一次設定**會生效

如果要重新設定，可以加上`force=True`，意思是不管之前有沒有設定過，都重新套用我目前這個設定

`filename="檔案名稱.log"`：設定 Log 要存在哪，副檔名是`.log`

`level=logging.INFO`：Log 要從哪個等級開始設定

等級如下：

| 等級 | 定義 |
|------|------|
| DEBUG | 開發人員除錯資訊 | 
| INFO | 正常運作資訊 | 
| WARNING | 有異常，但還能繼續 | 
| ERROR | 發生錯誤，部分功能失敗 | 
| CRITICAL | 嚴重錯誤，可能整個系統無法運作 | 


`format="%(asctime)s - %(levelname)s - %(message)s"`：格式化字串

- %(asctime)s : Log 發生時間  

- %(levelname)s : Log 等級

- %(message)s : 我自訂義的訊息

`encoding="utf-8"`：編碼

---

當我執行這個程式的時候，資料夾就會多出一個`system.log`的檔案

裡面會有這些資訊：

```
2026-08-20 22:14:25,893 - INFO - 系統啟動
2026-08-20 22:14:25,894 - INFO - 使用者登入成功
2026-08-20 22:14:25,894 - WARNING - API 回應速度過慢
2026-08-20 22:14:25,894 - ERROR - 資料庫連線失敗

```

  將系統事件分級為如下：

  - DEBUG：開發除錯

  　　例如：變數內容、API 回傳資料、程式執行流程

  - INFO：正常資訊

  　　例如：登入成功、資料載入完成、系統啟動

  - WARNING：有點異常，但系統還能繼續跑

  　　例如：API回應過慢、記憶體使用率偏高、資料缺少部分欄位

  - ERROR：某個功能或操作發生錯誤，但系統不一定完全停止

  　　例如：資料庫連線失敗、檔案讀取失敗、API呼叫失敗
  .
  - CRITICAL：非常嚴重，可能會影響整個系統

  　　例如：重要設定檔遺失、核心服務停止、系統無法啟動

## 第二步 - 分析 Log

　　同一個資料夾裡，再建立一個新檔案`log_analyzer.py`

　　這個檔案是用來**自動讀取 Log，抓出 ERROR**

　　範例程式碼：

```Python
with open("system.log", "r", encoding="utf-8") as file:
    logs = file.readlines()

for log in logs:
    if "ERROR" in log:
        print(log.strip())
```

```Python
with open("檔案名稱", "r", encoding="utf-8") as file:
    -> with = 管理檔案，使用完自動關閉
    -> open = 打開檔案
    -> "r" = 讀取模式
    -> UTF-8 = 編碼
    -> as file = 把開啟的檔案物件命名為 file

logs = file.readlines()
    -> file = 上一行讀取的資料
    -> readlines() = 每一行都讀取
    -> logs = 儲存讀取到的所有行

for log in logs:
    if "ERROR" in log:
    -> 如果 log 裡面有 ERROR
        print(log.strip())    strip() = 會去掉字串**前面和後面**的空白字元
        -> 就把它去除前後空白，然後顯示出來
```

|open()常見模式|功能|
|------|------|
| r | read   讀取 |
| w | write  覆寫 ( 原本的資料會不見 ) |
| a | append 追加 ( 寫在原本的資料後面 ) |
| x | create 建立 ( 如果檔案已存在就會報錯 ) |

### 第三步：統計 INFO、WARNING、ERROR 各有幾筆

　　在`log_analyzer.py`中，加入變數跟判斷式：

```Python
with open("system.log", "r", encoding="utf-8") as file:
    logs = file.readlines()

info_count = 0
warning_count = 0
error_count = 0

for log in logs:
    if "INFO" in log:
        info_count += 1

    elif "WARNING" in log:
        warning_count += 1

    elif "ERROR" in log:
        error_count += 1    

print("INFO 數量：", info_count)
print("WARNING 數量：", warning_count)
print("ERROR 數量：", error_count)
```

　　分成三個變數來記錄，用if else來判斷，如果有符合條件就加入指定變數

　　目前這一步是統計各種資訊各有多少而已

---

### 第四步：判斷目前系統有沒有異常

　　在`log_analyzer.py`中，加入一行判斷式：

```Python
if error_count > 0:
    print(f"系統存在{error_count}筆異常，請檢查 ERROR 紀錄")
else:
    print("系統目前無 ERROR")
```

　　如果error_count大於0，就顯示一共有幾筆異常，如果沒有就顯示沒有異常

　　f"文字 {變數}" = 在文字中直接插入變數的值，是一種**字串格式化**的方式

　　字串格式化，全名 f-string ( formatted string literal )

---

### 第五步：把實際的 ERROR 內容列出來

　　因為前一步只是告訴你一共有多少異常，而不會把異常的資料列出來

　　所以要在`log_analyzer.py`中，加入一個for迴圈，讓他列出 Error資訊

　　加入for迴圈會如下：
```Python
if error_count > 0:
    print(f"\n系統存在 {error_count} 筆異常")
    print("ERROR 紀錄：")

    for log in logs:
        if "ERROR" in log:
            print(log.strip())

else:
    print("系統目前無 ERROR")
```

　　第二次的 for 迴圈會重新逐行讀取 logs，找到包含 ERROR 的紀錄

　　再使用 strip() 去除前後空白與換行後顯示

　　其實第二次的for迴圈就是第二步出現的，只是跟 if / else 搭配使用了

---

### 第六步：優化程式碼，只用一次 for，同時統計與收集 ERROR

　　先建立一個空的串列，待會可以加入ERROR的紀錄

　　在第一次for迴圈時，原先只有`error_count += 1`來做統計數量

　　可以再加入`error_logs.append(log.strip())`，順便將錯誤資訊保存在串列裡面

　　這樣子就不需要再判斷一次：`if "ERROR" in log`

　　等於在這次判斷式中，我就可以完成**統計數量**以及**儲存錯誤資訊**這兩件事

　　可以避免後面重複再做一次一樣的事情，當 Log 資料量越大時，減少重複掃描的效果也會越明顯

---

### 第七步：讓使用者自己輸入關鍵字搜尋 Log

　　前面會將所有的錯誤資訊列出，當 Log 數量變多的時候會不易查找到需要的資訊

　　故可以加入`input()`，讓使用者自行輸入要查找甚麼資料

　　這樣可以精確的顯示使用者需要的資料，不需瀏覽全部資料

　　修改後程式碼如下：
```Python
if error_count > 0:
    print(f"\n系統存在 {error_count} 筆 ERROR 異常")
else:
    print("\n系統目前無 ERROR")

keyword = input("\n請輸入要搜尋的關鍵字：")

search_count = 0

for log in logs:
    if keyword in log:
        print(log.strip())
        search_count += 1

if search_count == 0:
    print("查無符合的 Log 紀錄")
else:
    print(f"\n共找到 {search_count} 筆紀錄")
```

### 第八步：加上 CRITICAL，讓程式判斷系統目前的異常等級

　　目前沒有加上 CRITICAL 等級(Log中最嚴重的等級)的判斷式

　　先新增`critical_count = 0`，讓他有個紀錄的變數

　　再來for迴圈中，也要加入 `elif "CRITICAL" in log:` 的判斷式

　　加上判斷嚴重等級的程式碼：
```Python
if critical_count > 0:
    print("Log 狀態：嚴重異常")

elif error_count > 0:
    print("Log 狀態：異常")

elif warning_count > 0:
    print("Log 狀態：警告")

else:
    print("Log 狀態：正常")
```

　　這樣子就會出現當前 Log 嚴重等級

### 第九步：避免找不到 Log 檔案時，程式直接當掉

　　這時候就可以加上例外處理，try / except

```Python
try:
    with open("system.log", "r", encoding="utf-8") as file:
        logs = file.readlines()

except FileNotFoundError:
    print("找不到 system.log，請確認 Log 檔案是否存在")
    sys.exit()
```

　　先在程式碼的最上方`import sys`

　　加上`try:`，意思是先嘗試打開system.log，如果可以正常打開就繼續執行

　　下一行`except FileNotFoundError:`，意思是如果**找不到檔案**，就執行下面的程式

　　`sys.exit()`，意思是結束目前的程式

　　如果打得開就繼續以下程式，如果打不開就給提示且結束目前程式

### 第十步：只分析最近 10 分鐘內的 Log 

　　要使用時間的話，就要在最上方加入`from datetime import datetime, timedelta`

　　datetime -> 處理日期時間 ; timedelta -> 處理時間差

　　加入這一段程式碼：
```Python
recent_logs = []

ten_minutes_ago = datetime.now() - timedelta(minutes=10)

for log in logs:
    try:
        time_text = log.split(" - ")[0]

        log_time = datetime.strptime(
            time_text,
            "%Y-%m-%d %H:%M:%S,%f"
        )

        if log_time >= ten_minutes_ago:
            recent_logs.append(log)

    except ValueError:
        continue  
```

　　第二行的意思是現在時間減10分鐘

　　`time_text` 意思是把文字轉時間，因為目前看起來是時間沒錯，但實際上Python把他當成字串

　　`"%Y-%m-%d %H:%M:%S,%f"`是用來把字串格式化，讓Python知道：我的時間格式是「年-月-日 時:分:秒,毫秒」

　　`if log_time >= ten_minutes_ago:`這段主要就是判斷資料是否有在10分鐘內，如果有就append，沒有就略過

　　這樣就可以不用再分析全部 Log，只分析最近 10 分鐘的 Log
