### `import logging`至程式內

　　範例程式碼 :
```Python
import logging

logging.basicConfig(
    filename="system.log",
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s",
    encoding="utf-8"
)


def read_file():
    try:
        with open("data.txt", encoding="utf-8") as file:
            data = file.read()

        logging.info("檔案讀取成功")

        return data

    except FileNotFoundError:
        logging.error("找不到 data.txt")

　　 　　return None

```

　　將logging與相關設定加入到需要產生Log的程式中

　　print() -> 是給使用者看的

　　logging.([分級](/blog/posts/log_tools/20260820_learn_log1#%E7%AD%89%E7%B4%9A%E5%A6%82%E4%B8%8B)) -> 是紀錄Log用的

　　發生例外的地方，logging 常會搭配 try / except 使用，這樣子正常執行流程時也可以使用 logging 紀錄事件

### 將真正需要產生Log紀錄的地方加上程式碼

　　原則：記**重要事件**、**異常**、**關鍵流程**，不要將每一行程式都加上Log

　　當你記錄的東西越多，Log紀錄會越混亂，而且真正的錯誤會更不易找到

　　Log訊息中也切記**不要放入機密資料**，例如：密碼、APIKey

#### 等級如下：

| 等級 | 定義 |
|------|------|
| DEBUG | 開發人員除錯資訊 | 
| INFO | 正常運作資訊 | 
| WARNING | 有異常，但還能繼續 | 
| ERROR | 發生錯誤，部分功能失敗 | 
| CRITICAL | 嚴重錯誤，可能整個系統無法運作 | 

　　實務上值得記的地方大約分成幾類：

* 系統生命週期：系統啟動、正常結束

* 重要功能完成：匯入完成、檔案產生完成、批次處理完成

* 外部服務：API、資料庫、檔案讀取

* 異常狀況：WARNING、ERROR、CRITICAL

* 操作結果：處理幾筆資料、成功/失敗數量

### 由main.py設定所有Log

　　把主程式會用到的其他`.py`模組可以由`main.py`統一設定logging

　　其他模組只需要`import logging`

　　並在需要的位置加入`logging.info()`、`logging.warning()`、`logging.error()`

　　這樣子可以不用在每個`.py`檔案中都設定一次logging設定檔

　　除非該檔案是會**單獨執行**再幫他加入設定logging的程式碼

　　例如：
```
main.py 
tool.py
```

　　把設定檔放在`main.py`，並且`import tool`

　　`import tool`時，Python會先執行`tool.py`裡面**最外層的程式碼**

　　如果`tool.py`裡面的功能是放在`def`裡，還是要另外呼叫函式才會執行

　　例如：我要執行tool裡的`def run_tool()`，我要再加入一行`tool.run_tool()`

　　當我執行`main.py`的時候就會一併執行`tool.py`(裡面要寫好需要產生log的程式碼)

　　執行完畢之後log資料就會出現在`.log`檔案中

　　但是當我單獨執行`tool.py`時：

　　因為`tool.py`沒有`main.py`裡的logging設定，所以不會按照`main.py`指定的方式寫入`.log`中

### 一些常用程式碼

| 程式碼 | 功能 |
|------|------|
|`import logging`|匯入logging函式庫|
|`logging.basicConfig(...)`|設定logging|
|`logging.錯誤等級()`|記錄[錯誤等級](/blog/posts/log_tools/20260823_learn_log3/#%E7%AD%89%E7%B4%9A%E5%A6%82%E4%B8%8B)訊息|
|`logging.exception()`|記錄完整錯誤訊息(Traceback)|
|`logging.shutdown()`|確實關閉logging|
|`logger = logging.getLogger(__name__)`|建立模組 logger|

--- 

### `logger = logging.getLogger(__name__)`用法

　　在程式碼中加入`logger = logging.getLogger(__name__)`

　　就可以在設定檔加入`%(name)s`

```Python
logging.basicConfig(
    filename="system.log",
    level=logging.INFO,
    format="%(asctime)s - %(name)s - %(levelname)s - %(message)s",
    encoding="utf-8"
)
```

　　這樣子紀錄log時會更清楚看到是哪一個`.py`檔的log

　　例如：

```
2026-08-23 22:10:30 - excel_tool - INFO - Excel讀取成功
2026-08-23 22:10:35 - database - ERROR - 資料庫連線失敗
```

　　這樣就很一目了然 時間 - 檔案 - 錯誤等級 - 訊息
