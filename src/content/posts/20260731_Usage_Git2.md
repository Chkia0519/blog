繼前篇安裝好Git之後，需要做第一次的設置

因為Git是分散式的版本控制系統，所以每一台機器都需要設定 名字和Email 

設置Git的程式碼如下:

```

$ git config --global user.name " 名字 "
$ git config --global user.email " Email "

```
> [!IMPORTANT]
> `git config` 指令的 `--global` 參數，用了他等於這台機器所有的Git倉庫都會用這個名字與Email

--global 就是 **全域設定** *的意思
