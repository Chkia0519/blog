### 抓錯字好朋友

`Option Explicit` -> 偵錯，固定放在VBA程式碼最頂部

例如：`Dim customerNo As String` 

　　**原本宣告的變數是`customerNo`**

- 沒有設定`Option Explicit`的狀況：

　　在底下的程式碼中不小心打成`customNo`，VBA就會以為`customNo`是新的變數，然後繼續執行程式

- 有設定`Option Explicit`的狀況：

　　VBA 就會直接提醒你**變數未定義**

### 在 VBA 中很像 Python `def()` 的程式碼們

1. Sub -> 執行一件事，但不會回傳結果
 
```VB
Sub 巨集名稱()

    程式碼

End Sub
```
Sub XXX()：最常見，直接執行巨集

Sub XXX(參數)：給其他 VBA 程式呼叫時比較常用

2. Function  -> 執行一件事，會回傳結果 (比較像 `def()` )

```VB
Function 計算(a As Long) As Long
    
    計算 = a * 2
    
End Function
```

```
Function 計算(a As Long) As Long
          ↑     ↑          ↑
       函數名稱  輸入參數    回傳值型別
```

`(a As Long)` -> 接收一個 Long 型別的 a

` As Long` -> 這個 Function 回傳的值型別是 Long

`計算 = a * 2` -> 等於 Python 中的 `return a * 2`

> [!TIP]
> Python 主要統一用 `def`，要不要回傳值由 `return` 決定
>
> VBA 則把它拆成 `Sub` 和 `Function` 兩種

### 設定變數

Const = 常數

Dim   = 變數

```VB
Const PATH As String = "C:\test.xls"
'PATH 是常數，型別字串，固定不變

Dim row As Long
'row 是變數，型別整數(無小數點) 可以一直變化
```

### VBA 型別表格

| VBA 型別 | 用途 | 範例 | 大概範圍 / 說明 |
|------|------|------|------|
| `String` | 文字 | `"王小明"`、`"02550111"` | 字串 |
| `Long` | 整數 | `10`、`50000` | 約 -21 億～21 億 |
| `Integer` | 小範圍整數 | `10`、`100` | -32768～32767 |
| `Double` | 有小數的數字 | `12.9`、`3.14159` | 適合一般小數計算 |
| `Single` | 有小數的數字 | `12.5` | 精度比 Double 低 |
| `Boolean` | 是 / 否 | `True`、`False` | 只有真假 |
| `Date` | 日期、時間 | `2026/8/26` | 日期與時間 |
| `Currency` | 金額 | `1234.56` | 適合貨幣計算 |
| `Byte` | 很小的非負整數 | `0`～`255` | 只能 0～255 |
| `Variant` | 什麼都能放 | 文字、數字、日期  | 彈性最大，但較不嚴謹 |
| `Object` | 物件 | Excel 物件 | 泛用物件 |
| `Workbook`| Excel 活頁簿 | `ThisWorkbook`       | Excel 專用物件型別 |
| `Worksheet` | Excel 工作表 | `Worksheets("INV")`  | Excel 專用物件型別 |
| `Range` | 儲存格/範圍 | `Range("A1")`        | Excel 專用物件型別 |
