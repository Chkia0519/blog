Astro 是一個用來建立網站的 JavaScript 網頁框架

我會選擇 Astro，是因為它產生的網站介面簡潔、閱讀起來舒服，而且整體相對輕量，很適合拿來建立部落格

我可以用 Markdown 來撰寫文章，再透過 Astro 將 Markdown 文章轉換為靜態網站頁面

因為 Astro 可以產生靜態網站，所以可以直接在 GitHub Page 上部屬

之後我只要更新文章並將修改推送到 GitHub，就能更新部落格內容

這次建置主要是在 AI 的逐步協助下完成

雖然目前還不能完全獨立寫出整個網站，但透過實際操作，我開始了解 Markdown、Astro、GitHub、版本控制與網站部署之間的關係

未來如果有更多功能需求，也會繼續學習如何整合 React、Vue或 Svelte 等前端工具

這篇主要是我拿來記錄當時怎麼部屬 Astor 的學習記錄

## 第一步：確認 Node.js 和 npm

在終端機中輸入 `node v` 來確認 Node.js

在終端機中輸入 `npm -v` 來確認 npm

如果兩個指令都有出現版本的號碼，就代表已經有安裝

但是如果是出現**不是內部或外部命令**就是沒有安裝

---

這邊我就有幾個好奇的問題了

### 我不是用 Astor 來建立部落格嗎，為甚麼我需要安裝 Node.js 和 npm

Node.js 是執行環境

npm 是套件管理工具

Astro 是實際用來建立網站的框架

流程帶大概是這：

```
Node.js 提供執行環境
       ↓
npm 安裝及管理 Astro
       ↓
Astro 將 Markdown、版型與程式碼建置成網站
       ↓
部署到 GitHub Pages
```

- 為甚麼需要 Node.js

因為 Node.js 是一個可以讓電腦直接執行 JavaScript 的工具

在開發 Astro 網站時，Node.js 主要負責：

1. 執行 Astro 的開發工具
2. 啟動本機預覽伺服器
3. 讀取 Markdown 文章
4. 處理網頁、CSS 與圖片
5. 將專案建置成可部署的靜態網站

當我執行 `npm run dev` 就是透過 Node.js 啟動 Astro 的開發伺服器

如果沒有 Node.js，電腦就無法正常執行 Astro 的開發工具

Astro 官方也將 Node.js 列為安裝 Astro 的必要條件

- 為甚麼需要 npm

npm 是 Node Package Manager，中文稱為 **Node 套件管理工具**

Astro 本身以及網站使用的其他功能，都是一個個可以安裝的套件

npm 會幫忙：

1. 下載 Astro
2. 安裝專案需要的其他套件
3. 記錄套件版本
4. 更新或移除套件
5. 執行專案內設定好的指令

`npm create astro@latest` 

這個指令會下載並啟動 Astro 的專案建立工具，引導你建立新的網站

這也是 Astro 官方建議建立新專案的方式

如果已經有 Astro 專案，輸入`npm install`

npm 會幫忙檢查專案裡的 package.json，再把需要的套件安裝下來

他們兩個都非常重要，也難怪 Astro 會把他們列為安裝 Astro 的必要條件
