### 11. 顯示 commit 上的標籤 - `git log --decorate`

　　因為一次顯示會顯示很多資訊，大多會加上 `--oneline`

　　 `git log --oneline --decorate`

　　輸出範例如下：
```
030046f (HEAD -> main, origin/main, origin/HEAD) 'Git7_Updata'
2de1de2 '更新日記'
cd99e78 'log筆記'
d728c61 '更新日記'
```

　　HEAD -> main，就是目前　HEAD 在 main 分支上，就是我目前所在的位置

　　origin/main, origin/HEAD，是遠端目前的位置

　　現在的狀態就是本地端跟遠端在的位置是一致的

    HEAD
    = 你目前站的位置

    main
    = 本機 main 分支

    origin/main
    = GitHub 上的 main 分支位置

    origin/HEAD
    = GitHub 的預設分支

　　他就等於幫 commit 加上「這是哪個分支／標籤的位置」標記

　　很常跟[`--graph`](/blog/posts/20260804_usage_git6/#3%E6%9F%A5%E8%A9%A2%E5%88%86%E6%94%AF%E5%9C%96branch---git-log---oneline---graph---all)一起使用
