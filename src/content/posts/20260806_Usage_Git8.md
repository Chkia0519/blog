### 11. 顯示 commit 上的標籤 - `git log --decorate`

　　因為一次顯示會顯示很多資訊，大多會加上 `--oneline`

　　 `git log --oneline --decorate`

　　輸出範例如下：
```
030046f (HEAD -> main, origin/main, origin/HEAD) 'Git7_Updata'
2de1de2 '更新日記'
cd99e78 'log筆記'
d728c61 '更新日記'
```
　　其中 `HEAD -> main` ，代表目前　HEAD 在 main 分支上，而 main 分支目前再指向這個 Commit

　　`origin/main`, `origin/HEAD`，代表本機**目前記錄的**遠端 origin 的 main 分支位置

　　如果本機 `main` 與 `origin/main` 都指向同一個 Commit，代表目前本機與已知的遠端狀態一致

    HEAD
    = 你目前在的位置

    main
    = 本機 main 分支

    origin/main
    = 本機記錄的遠端 main 分支位置

    origin/HEAD
    = 遠端 origin 的預設分支指向

　　`--decorate`可以理解成幫 commit 加上 HEAD、Branch、Tag、遠端分支目前指向哪裡」的標記

　　很常跟[`--graph、--all`](/blog/posts/20260804_usage_git6/#3%E6%9F%A5%E8%A9%A2%E5%88%86%E6%94%AF%E5%9C%96branch---git-log---oneline---graph---all)一起使用

　　範例：`git log --oneline --graph --decorate --all`

#### 這樣可以同時看到：

- 所有分支

- Commit 關係圖

- HEAD 在哪

- 各分支指向哪個 Commit

> [!TIP]
> `--all`       → 看所有分支
> 
> `--decorate`  → 看分支目前指在哪
> 
> `--graph`     → 看分支怎麼分出去、合回來

### 12. 追蹤檔案改名前的歷史 - `git log --follow '檔案名稱'`

　　如果檔案曾經**重新命名**，Git 的歷史查詢可能只顯示目前檔名相關的紀錄

　　所以可以用`git log --follow '檔案名稱'`，來繼續追蹤檔案重新命名前的 Commit 歷史

　　這個參數特別適合整理專案歷史時使用

　　範例：

　　我原本的檔案叫 text.py ，但我後來改成 main.py

　　我如果用`git log main.py `，只會看到改名字後的 commit

　　但是如果我用`git log --follow main.py `，就會連 text.py 時期的 commit 一起給我

### 13. 查看改了哪些檔案 - `git log --name-only`

　　會直接把改了哪一些show出來，不會跟[`--stat`](/blog/posts/20260804_usage_git6/#5%E6%9F%A5%E7%9C%8B%E6%AF%8F%E6%AC%A1-commit-%E6%94%B9%E4%BA%86%E5%93%AA%E4%BA%9B%E6%AA%94%E6%A1%88---git-log---stat)一樣顯示增減行數

　　`--name-only`範例：
```
commit 2de1de20a1f7ab2b2358870ea5c5e11d682fa98e
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Wed Aug 5 18:07:31 2026 +0800

    '更新日記'

src/content/posts/20260729_Usage_Md.md
src/content/posts/20260730_Usage_GitAll.md
src/content/posts/20260804_Usage_Git6.md
src/content/posts/20260805_Usage_Git7.md　
```

　　`--stat`範例：
```
commit 2de1de20a1f7ab2b2358870ea5c5e11d682fa98e
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Wed Aug 5 18:07:31 2026 +0800

    '更新日記'

 .../{20260729_Usage.md => 20260729_Usage_Md.md}    |  0
 src/content/posts/20260730_Usage_GitAll.md         |  6 +++-
 src/content/posts/20260804_Usage_Git6.md           | 41 +++++++++++++++-------　
```

> [!TIP]
> 
> --name-only → 只看改了哪些檔案
> 
> --stat      → 看改了哪些檔案＋增刪幾行
> 
> -p          → 看實際哪幾行被修改


資訊量由少到多

--name-only
    ↓
--stat
    ↓
-p

### 14. 顯示修改檔案與狀態 - `git log --name-status`

　　可以查看每次 Commit 修改了哪些檔案

　　並且同時知道這些檔案是 新增、修改、刪除，還是重新命名

　　範例：
```
commit 2de1de20a1f7ab2b2358870ea5c5e11d682fa98e
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Wed Aug 5 18:07:31 2026 +0800

    '更新日記'

R100    src/content/posts/20260729_Usage.md     src/content/posts/20260729_Usage_Md.md
M       src/content/posts/20260730_Usage_GitAll.md
M       src/content/posts/20260804_Usage_Git6.md
A       src/content/posts/20260805_Usage_Git7.md

```
　　在檔案的前面的英文字母就代表檔案狀態：

　　A = Added 新增檔案

　　M = Modified 修改檔案

　　D = Deleted 刪除檔案

　　R = Renamed 重新命名檔案　　

---
　　**和 `--name-status` 的差別**
　　
　　`--name-only`只會顯示這次 commit 動到哪一些檔案，但不會顯示是對檔案做了甚麼操作

---
　　**和 `--stat` 的差別**　

　　`--stat`只會顯示這次 commit 動到哪一些檔案，以及增刪多少行的視覺圖

---

|程式碼|動作|
|------|------|
|`--name-only` | 這次改了哪些檔案|
|`--name-status` | 這次改了哪些檔案 + 檔案狀態|
|`--stat` | 這次改了哪些檔案 + 增刪多少行|

---

### 15. 反轉 Commit 顯示順序 `git log -reverse`

　　一般使用 `git log` ，git 會從**新->舊**來做顯示

　　如果想從舊看到新，就可以使用`git log --reverse`來看

> [!TIP]
>　git log -> 新到舊
>
>　git log --reverse -> 舊到新

### 16. 搜尋檔案內容裡的變化 - `git log -S"文字"`

　　可以查找特定文字是在哪次 commit 被加入或刪除

　　範例：
　　
　　假如我`main.py`裡面原本沒有 login()

　　後來某次 commit 新增了 login()

　　執行 `git log -S"login"` 之後，Git 就會尋找與`login`出現次數變化有關的 commit 

　　例如原本是：
```
print("Hi")
```

　　後來變更為：
```
print("Hi")
login()
```

　　原本`login()`出現次數是 0，但後來新增了，所以前後兩個版本相比，出現次數從 0 變成 1

　　但如果原本出現次數為 1，後來刪掉了變成 0，這次的 commit 也會被找出來

　　不管是 `0 -> 1` 或是 `1 -> 0` ，只要有次數變化就會被找出來
---

- 和 [`--grep`](/blog/posts/20260805_usage_git7/#7-%E7%AF%A9%E9%81%B8-commit-%E8%A8%8A%E6%81%AF-----grep)的差別

　　`git log --grep="文字"` -> 搜尋 Commit 訊息 

　　`git log -S"文字"` -> 搜尋檔案內容中這段文字的增減歷史　

---

- 搭配 `-p` 可以查看實際修改狀況

　　`git log -p -S"login"`

　　會顯示：

```
+ def login():
+     print("登入成功")
```

　　這樣子就可以看到實際上`login`是怎麼被加入的

---

- 限定搜尋某個檔案

　　`git log -p -S"login" -- main.py`

　　就是只在`-- main.py`中尋找關於`login`相關的增減紀錄

　　其中：

　　`-S"login"` -> 搜尋 `login` 這段文字的出現次數變化

　　`--` -> 告訴 Git 後面開始是檔案或路徑

　　`main.py` ->限定只搜尋 `main.py`

★　`git log -p -S"login" -- main.py` 的 `--` 和 `檔案` 之間一定要空格

---

> [!IMPORTANT]
> `-S`並非單純搜尋哪個 Commit 的檔案**包含**這段文字
>
> 而是尋找哪些 Commit 讓指定文字的**出現次數**發生改變。
