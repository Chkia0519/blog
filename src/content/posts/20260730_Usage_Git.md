## Git是甚麼?

版本控制的好夥伴，可以清楚明瞭知道誰改了哪一些東西

不用有更動就另存新檔，這樣會變成很多文件，也無法知道更動了哪些東西

---

## 檢查有無安裝

可以先在CMD/PowerShell裡輸入`git`，看看系統有沒有安裝Git了

如果出現usage然後一長串如何操作的字之類的(?)就是已經安裝

出現以下程式碼就是沒有安裝

```
$ git
The program 'git' is currently not installed. You can install it by typing:
sudo apt-get install git

```

## 安裝

- ### Linux

    Debian或Ubuntu Linux可以在cmd中輸入`sudo apt install git`，就可以直接安裝

    但是如果是Linux的其他版本，就需要看發行版的說明

    例如：RedHat Linux可以透過指令`sudo yum install`git安裝

    --- 

- ### MacOS

    1. 安裝套件管理器[Homebrew](https://brew.sh/)，再透過Homebrew安裝Git（建議）
    
        `$ brew install git`

    2. 第二種方法比較簡單，但需要下載一個巨大的XCode。
    
        直接從AppStore安裝[Xcode](https://developer.apple.com/xcode/)，Xcode整合了Git
        
        但預設Mac沒有安裝，你需要執行Xcode，選擇選單“Xcode”->“Preferences”，在彈出視窗中找到“Downloads”，選擇“Command Line Tools”，點“Install”就可以完成安裝了。

    ---

- ### Windows

    1. 從Git官網直接下載[安裝檔][https://git-scm.com/install/windows]

        裝好之後在開始功能表裡找到“Git”->“Git Bash”，會跳出一個類似命令提示字元視窗的東西，就表示Git安裝成功了。

    2. 安裝套件管理器，推薦[Scoop](https://scoop.sh/)，然後在PowerShell中透過以下指令安裝Git：

        `C:\> scoop install git`
        安裝完成後打開CMD/PowerShell，輸入`git -v`就會出現目前Git的版本為何



> [!TIP]
> 學會PowerShell之後可以學習使用套件安裝，升級版本時會更便利
