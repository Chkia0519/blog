### 6. 篩選作者 - `git log --author`

　　**在多人協作的時候，可以用來查看特定作者更動了哪一些項目**

　　`git log --author="作者名稱"`

　　範例如下：

```
commit d16a3c2d0f77ed87f9c3f3a70e703f18471dbb07
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Mon Aug 3 17:25:49 2026 +0800

    '更新Git筆記'
```

　　可以篩選commit的作者是誰，作者名稱是一開始用`git config user.name`設定的名字喔

　　也可以加上`--oneline`讓查詢出來的結果更簡潔

　　加上`--oneline`後的範例：

```

2de1de2 (HEAD -> main, origin/main, origin/HEAD) '更新日記'
cd99e78 'log筆記' -> HEAD
d728c61 '更新日記'
3f085ea '更新日記'

```
　　會從進到遠開始顯示該作者所有的commit

### 7. 篩選 commit 訊息 - `--grep`

　　可以從 commit 歷史中，找出**提交訊息包含特定關鍵字**的紀錄

　　`git log --grep="關鍵字"`

　　例如：`git log --grep="日記"`

　　就會只出現 commit 訊息裡面有"日記"的紀錄，不會篩選程式碼裡面的內容喔

　　範例如下：

```
commit 13ab379f833f381f3c6c386335be0c1f08910d26
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Sun Aug 2 22:26:17 2026 +0800

    '更新日記'

commit b524f8d1ce8e9bb5f4dfea1e8490e4100bcf794c
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Fri Jul 31 17:45:50 2026 +0800

    '更新第一篇Git學習日記-安裝'
```

### 8. 依照日期篩選 commit - `--since`、`--until`

- 查看某日期之後 - `--since`

　　`git log --since="2026-08-01"` 

　　代表查看2026-08-01**後**的commit

- 查看某日期之前 - `--until`

　　`git log --until="2026-08-01"`

　　代表查看2026-08-01**前**的commit

- 查看日期區間 - `--since`+`--until`

　　`git log --since="開始日期" --until="結束日期"`

　　`git log --since="2026-08-01" --until="2026-08-05"`

　　代表查看2026-08-01~2026-08-05的commit

- 查看相對時間 - `--since="1 week ago"`

　　`--since="1 week ago"` -> 查看最近一周

　　`1 day ago`、`1 month ago`，這兩個也很常用

### 9. 篩選特定檔案 - `git log -- 檔案名稱`

　　可以看單一檔案的歷史紀錄

　　`git log -- src/content/posts/20260730_Usage_GitAll.md`

　　會顯示：
```
commit 183b07d1ac6879166cf1f5ade77d0dec89882e2a
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Thu Aug 6 18:00:14 2026 +0800 

    'log日記3'

commit 2de1de20a1f7ab2b2358870ea5c5e11d682fa98e
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Wed Aug 5 18:07:31 2026 +0800

    '更新日記'
    以下略(太多了)
```

　　如果我沒有cd到檔案所在位置，就要用檔案的相對路徑查

　　相對路徑 -> 相對路徑就是「從我目前所在的位置，要怎麼走到那個檔案」

　　上面範例因為我現在在C:\blog裡，所以我是從src開始

### 10. 篩選特定 commit id 後所有的版本 - `git log <commit-id>..HEAD`
　　
　　假設我今天有東西被修壞了，我要查看某一次版本到最近的這次就可以用這個

　　假設歷史：
```
A → B → C → D → E
                ↑
              HEAD
```

　　我用`git log C..HEAD`，就先會給我E的資料再給我D，但**不包含**C

　　因為Git會從HEAD先開始顯示，所以會如下：

```
e123456 更新日記

d123456 更新總覽
```

---

> [!TIP]
> 查詢時可以加入`--oneline`，讓輸出結果更簡潔易讀
>
> `--oneline` 是顯示格式參數，所以通常可以和大部分 git log 篩選條件一起搭配使用
