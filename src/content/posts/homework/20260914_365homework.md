#### 一、 數位轉型有哪四大支柱？ 如果您還在職工作，請以您公司為例思考如何進行數位轉型，如您未在職工作，請任選擇一家您所知道的公司或企業（例如：柯達） 思考如何為其數位轉型，以避免倒閉或是為公司開創更好的契機。（30 分）

1. 數位轉型有哪四大支柱？

- 核心：數位技術的應用
- 面向：組織文化、流程、技術、人才等全面轉型
- 領導階層：清晰的願景及策略，能組織資源以便實施數位化轉型
- 員工：對應的技術和知識，能適應數位技術的應用以及新的工作方式

2. 我過去的公司是電商業，主要工作都還是以較為傳統的方式

紀錄訂單也都是為本機紀錄及人工操作，因為幾乎都是人工，故無法創造多餘時間來進行策略

目前數位轉型我有想到的是將瑣碎工作交由系統化處理，就可以有效利用時間

- 商品庫存做資料集中管理，因為目前都是全數分開，會有很多無法及時去發現已缺貨導致超賣

- 分析銷售及購買客群以及常見問題，可以利用訓練LLM來個人化分析，後續以利做銷售決策

- 員工培訓數位化，因為有一位員工每次在教導新人都會亂教，如果有數位化來統一教學就不會有這些人為的問題

所以其實數位轉型的目的不只是導入新工具，而是透過系統節省作業時間，並把資料轉化為有助於改善服務與經營的資訊

推動時可先從最耗時的流程開始，逐步導入並培訓員工，讓轉型更符合實際需求，也能提升公司的競爭力

####  二、 什麼是 Azure？請任舉三種 Azure 所提供的服務。（20 分）

1. 什麼是 Azure？

- Azure 是微軟提供的雲端運算平台

雲端運算平台：透過網路，使用別人提供的電腦資源與服務，如儲存資料、執行程式，不用自己購買和維護伺服器

2. 請任舉三種 Azure 所提供的服務

- 虛擬機器：建構雲端虛擬主機

- 雲端儲存：類似google雲端硬碟

- Azure SQL 資料庫
