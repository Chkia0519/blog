#### 1. 請繪出 Java 應用程式開發的流程圖，內容至少包含「撰寫程式」、「編譯程式」及「執行程式」三個步驟，並標示發生「編譯錯誤」或「執行錯誤」時的處理方式，以及各步驟所使用的軟體。請附上自己使用Eclipse 操作 Java 程式的畫面截圖。 (20%)

#### 2. 接上題，請說明如何在 Eclipse 中建立、編譯及執行一個 Java 程式。請自行建立一個簡單的 Java 程式，輸出自己的「姓名」及「學號末三碼」，並附上程式碼及 Eclipse 執行結果截圖。 (20%)

#### 3. 請撰寫一個 Java 圖形程式，可以繪製一個簡單的函數圖形，並繳交程式碼及執行結果截圖。完成後，請將程式修改為繪製 y = 2x + 1 的函數圖形，並附上修改後的程式碼及執行結果截圖。 (30%)

#### 4. 請撰寫一個 Java 應用程式，自行設定兩個數字，並分別計算及顯示這兩個數字的加、減、乘、除結果。請繳交程式碼及執行結果截圖。完成後，請將程式中的兩個數字更換為其他數值，再執行一次，並附上修改後的執行結果。 (30%)
