先在已經做了　`git init` 的目錄中新增一筆資料

一定要放在目錄底下，放在其他地方的話 Git 找不到也無法進行版本控制

新增好資料之後，可以用 `git add` 來加入版本控制

單一檔案：`git add 檔案名稱`

全部檔案：`git add .` .是全部的意思

`git add` 就是將檔案加到 Git 的暫存區，當你用 `git status` 查看狀態時，就會看到你暫存了哪一些文件

---

將檔案加到暫存區之後，就可以用 `git commit -m '更新了哪一些資訊'` 來建立版本紀錄

`-m` 後面接的是本次提交（Commit）的說明，無論是自己使用或是協同作業都可以清楚閱覽做了哪一些更動

---

最後是用 `git push` 將檔案上傳到 Github 倉庫，這樣子就完成第一次的版本紀錄了

> [!TIP]
> `git add` -> `git commit -m '更新內容'` -> `git push`
