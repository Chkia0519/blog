先前已經在做了　`git init` 的目錄中新增一筆資料

資料一定要放在該目錄底下，放在其他地方的話 Git 找不到也無法進行版本控制

---

## 1. 確認狀態 - `git status`

　　可以先用 `git status` 確認目前狀態

　　但目前還沒將檔案add，所以會出現：
```
    Untracked files:
   　　
    檔案.py
```

　　`Untracked` -> 尚未追蹤的意思

　　Git 知道有這個資料，但因為還沒有追蹤，所以目前狀態就是Untracked

---

## 2. 加入暫存區 - `git add`

　　確認好狀態之後，可以用 `git add` 來加入暫存區進行版本控制

　　單一檔案：`git add 檔案名稱`

　　全部檔案：`git add .` .是全部的意思

　　`git add` 就是將檔案加到 Git 的暫存區

　　當你用 `git status` 查看狀態時，就會看到你暫存了哪一些文件：

```
Changes to be committed:

    new file: 檔案.py
```

---

## 3. 建立版本紀錄 - `git commit`

　　將檔案加到暫存區之後，就可以用 `git commit -m '更新了哪一些資訊'` 來建立版本紀錄

　　`-m` 後面接的是本次提交（Commit）的說明

　　無論是自己使用或是協同作業都可以清楚閱覽做了哪一些更動

　　git commit 的意思是建立版本快照，-m 的意思是 message

　　**白話一點就是：建立一個版本，並把這次修改說明寫成 '更新了哪一些資訊'**

>[!IMPORTANT]
>**一個 Commit 盡量代表一件有意義的修改，所以盡量不要一次add .**

---

## 4. 上傳到遠端 - `git push`

　　最後是用 `git push` 將檔案上傳到 Github 倉庫，這樣子就完成第一次的版本紀錄了

　　**如果沒有push只有停在commit的話，版本只會儲存在本機，不會存在Git倉庫裡**

---

> [!TIP]
> `git add` -> `git commit -m '更新內容'` -> `git push`
> 
> 加到暫存 ->  在本機建立版本&添加說明  -> 推到遠端更新
