### 基本查詢與顯示方式

| 指令 | 用途 |
|------|------|
| `git log` | 查看完整 commit 歷史紀錄 |
| `git log --oneline` | 每個 commit 只顯示一行 **常用** |
| `git log -n` | 只顯示最近 n 筆 commit |
| `git log --reverse` | 將紀錄改成由舊到新顯示 |

---

### 查看 commit 修改內容

| 指令 | 用途 | 簡單記 |
|------|------|------|
| `git log --stat` | 查看每次 commit 修改哪些檔案，以及增刪多少行 | 改了哪些檔案，增減多少行 |
| `git log -p` | 查看每次 commit 實際修改了哪些內容 | 實際改了哪些 |
| `git log --name-only` | 只列出每次 commit 修改過的檔案名稱 | 改了哪些檔案 |
| `git log --name-status` | 顯示修改過的檔案名稱與狀態 | 改了哪些檔案，並顯示這些檔案更改的狀態 |
	
#### `--name-status` 常見狀態：

　A  Added  新增

　M  Modified  修改

　D  Deleted  刪除

　R  Renamed  重新命名

---

### 篩選 commit

| 指令 | 用途 |
|------|------|
| `git log --author="作者"` | 只篩選該作者的 commit |
| `git log --grep="文字"` | 搜尋 commit 訊息包含指定文字的紀錄 |
| `git log --since="日期"` | 查看指定日期**之後**的 commit |
| `git log --until="日期"` | 查看指定日期**之前**的 commit |
| `git log --since="開始日期" --until="結束日期"` | 查看指定日期區間的 commit |

這些篩選條件可以一起使用：

`git log --oneline --author="Chkia" --grep="登入"`

意思是：篩選作者為"Chkia"，且 commit 訊息包含"登入"

---

### 篩選特定檔案的 commit 歷史紀錄

- 追蹤目前檔案的歷史 `git log -- 檔案名稱`

- 追蹤**改名前**的歷史 `git log --follow -- 檔案名稱`

　　如目前未cd到檔案所在地，需要在檔案名稱那邊打出相對路徑

　　-- 和檔案名稱中間需要空格，如果沒空格就是語法錯誤

---

### 搜尋檔案內容的變化

- `git log -S"文字"`

　　尋找哪些 commit 讓 "文字" 的出現次數發生變化

- `git log -p -S"login"`

　　加上 `-p` 可以直接查看實際的修改狀況

- `--grep` 與 `-S` 的差別

| 指令 | 用途 |
|------|------|
|`--grep`| 搜尋 commit 訊息 |
|`-S"文字"`| 搜尋**檔案內容**中 特定文字的增減歷史 |

---

### 查看 branch(分支) 與 commit 關係

| 指令 | 用途 | 簡單記 |
|------|------|------|
|`git log --graph`| 用線條圖顯示 commit 的分支與合併關係| 用線條畫出分支的走向 |
|`git log --all`| 顯示所有分支可到達的 commit | 查看分支所有歷史 |
|`git log --decorate`| 顯示 HEAD、branch、tag、遠端追蹤分支等參照標記 | 顯示標記分別指向哪 |

---

### 速查表


| 指令 | 用途 |
|------|------|
|`git log`| 查看所有歷史 |
|`git --oneline log`| 查看簡潔歷史 |
|`git log -n`| 查看n筆 |
|`git log --reverse`| 舊->新 |
|`git log --stat`| 查看增減行數 |
|`git log -p`| 查看修改甚麼 |
|`git log --name-only`| 只看修改過的檔名 |
|`git log --name-status`| 查檔案名稱與修改狀態 |
|`git log author="作者"`| 查指定作者 |
|`git log --since="日期"`| 查某日期之後 |
|`git log --until="日期"`| 查某日期之前 |
|`git log --since="開始日期" --until="結束日期"`| 查特定日期區間 |
|`git log -- 檔案名稱`| 查特定檔案的歷史 |
|`git log --follow -- 檔案名稱`| 查特定檔案**改名前**的歷史 |
|`git log --grap="文字"`| 搜尋**commit 訊息** |
|`git log -S"文字"`| 搜尋**檔案中**文字增減歷史 |
|`git log -p -S"文字"`| 搜尋**檔案中**文字並且查看詳細修改內容 |+
|`git log --graph`| 看 commit 關係圖 |
|`git log --all`| 看所有分支 |
|`git log --decorate`| 看 HEAD、branch、Tag 標記 |
|`git log --oneline --graph --decorate --all`| 完整查看分支歷史 |
