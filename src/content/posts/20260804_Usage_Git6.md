上一篇有提到，可以用 `git status` 查看目前的狀態

當已經開始建立版本控制時，要查看過去的歷史就要用 `git log`

這一篇是在講怎麼使用 `git log` 查看過去的提交紀錄

因為想說log的部分有點長，就分成幾篇好了

---

- ###  在 CMD 中輸入 `git log`

　　理解為**打開存檔紀錄**

　　可以查看**所有**歷史提交過的紀錄，會由近到遠開始

　　會輸出如下範例：
```

commit 13ab379f833f381f3c6c386335be0c1f08910d26 -> Git 給的提交編號(類似身分證)
Author: Chkia0519 <a0986161178@gmail.com> -> 誰提交 commit 的
Date:   Sun Aug 2 22:26:17 2026 +0800 -> 甚麼時候commit的  +0800是時區

    '更新日記'  -> Commit 時提交的異動訊息

```

　　可以使用方向鍵或 Page Up / Page Down 瀏覽歷史紀錄

> [!TIP]
> 每次進入 log 後若想離開的話要按`q`才會離開喔!
---

### 1.只看近幾筆提交 - `git log -限制數量`

　　給限制條件之後可以不用每次都顯示**所有**的資料

　　例如 `git log -5`，後面的 -5 就是代表只查詢**最近5筆**的異動

---

### 2.簡潔查詢 - `git log --oneline` 

　　`--oneline` 就是每個 Commit 只用一行顯示，可以快速找到想找的資料，在業界中常常用到

　　會輸出如下範例：
```

25458f8 '更新日記'
13ab379 '更新日記'
b524f8d '更新第一篇Git學習日記-安裝'

```

　　前面的是`commit id`，也就是每一次 Commit 的時候 Git 給的提交編號(類似身分證)

　　後面的文字則是該次 Commit 提交的異動訊息

> [!TIP]
> Git 預設會由最新的 Commit 往最舊的 Commit 顯示，因此第一筆通常是最新的提交紀錄
> 
> 這筆 Commit 通常也是 HEAD 所指向的位置。
>
> [HEAD詳解-待補](/)
---

### 3.查詢分支圖(branch) - `git log --oneline --graph --all` 

　　--graph -> 把 Git 的 Commit 歷史用**線條圖**顯示出來

　　--all -> 查看**所有**分支的 Commit 紀錄

　　會輸出如下範例：
```

* a1b2c3d 修正登入問題
* d4e5f6g 新增會員功能
|\
| * h7i8j9k feature 分支修改
|/
* k1l2m3n 初始版本


```

　　可以清楚看到 Commit 之間的關係，以及分支與合併的路徑

　　目前還沒學到分支，之後要再補這邊的筆記

　　很常跟[`--decorate`](/blog/posts/20260806_usage_git8/#11-%E9%A1%AF%E7%A4%BA-commit-%E4%B8%8A%E7%9A%84%E6%A8%99%E7%B1%A4---git-log---decorate)一起使用

---

### 4.查看某次 Commit 改了哪些內容 - `git log -p`

　　`-p` = patch

　　會顯示更動了哪一些內容，但是 Git 不知道你是修改哪一行

　　用 + 代表增加的內容，用 - 代表刪減的內容

　　會輸出如下範例：
```
commit d728c6113a63b9ff54fc884a0dd83e6939c79b39 (HEAD -> main, origin/main, origin/HEAD)
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Tue Aug 4 17:57:32 2026 +0800

    '更新日記'

diff --git a/src/content/posts/20260730_Usage_GitAll.md b/src/content/posts/20260730_Usage_GitAll.md
index cdc7141..824a0e7 100644
--- a/src/content/posts/20260730_Usage_GitAll.md
+++ b/src/content/posts/20260730_Usage_GitAll.md
@@ -23,6 +23,9 @@ featured: true
 第四篇：[新增第一次版本紀錄](/blog/posts/20260802_usage_git4/)


-第五篇：[現在與過去](/blog/posts/20260802_usage_git4/)  -> 原本是這個內容，刪掉 所以是-
+第五篇：[現在狀態](/blog/posts/20260803_usage_git5/)    -> 更動為這個內容，新增 所以是-


``` 

　　+(資料A) 代表這次 Commit **新增** 資料A

　　-(資料B) 代表這次 Commit **刪除** 資料B

　　如果有指定要看n次，可以用`git log -p -n` ，n 代表是筆數 例如：-1 -2

> [!TIP]
> 因為`-p`一次會顯示很多資訊，可以搭配`--oneline`來使用會更好閱讀

---

### 5.查看每次 Commit 改了哪些檔案 - `git log --stat`

    `--stat` -> 可以理解成 statistics（統計）
    
    查看 Commit 歷史，並顯示每次 Commit 修改了哪些檔案，以及修改行數的統計

    會輸出如下範例：

```
commit d16a3c2d0f77ed87f9c3f3a70e703f18471dbb07
Author: Chkia0519 <a0986161178@gmail.com>
Date:   Mon Aug 3 17:25:49 2026 +0800

    '更新Git筆記'

 src/content/posts/20260730_Usage_Git.md    |  6 ++---
 src/content/posts/20260730_Usage_GitAll.md | 15 +++++------ 
 src/content/posts/20260731_Usage_Git2.md   |  7 +++---
 src/content/posts/20260801_Usage_Git3.md   | 13 +++++++---
 src/content/posts/20260802_Usage_Git4.md   | 40 ++++++++++++++++++++++++++----
 5 files changed, 58 insertions(+), 23 deletions(-)

```

　　某個檔案    |　　++++++    -> 新增的行

　　某個檔案    |　　----      -> 刪除的行

　　左邊的數字代表總變動行數

　　後面的++++---是一個視覺比例圖，並非實際刪除或增加的行數


| 5 files changed | 58 insertions(+) | 23 deletions(-) |
|------|------|------|
| 修改了5個檔案 | 新增了58行 | 刪除了23行 |

　　**也可以搭配`--oneline`來使用會更好閱讀，會縮短 Commit 的標頭資訊**


> [!TIP]　　
>   `--stat`  和 `-p` 的差別：
>
> `--stat` -> 看**改了哪些檔案、改了多少行**
> 
> `--p` -> 看**實際修改了哪些內容**
