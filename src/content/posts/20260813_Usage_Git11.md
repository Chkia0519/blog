`git show` 主要用來查看**指定 Commit 的詳細資訊**

且會顯示這筆 Commit 相較於前一筆 Commit 改了什麼

除了可以查看 Commit 資訊之外，也可以查看：

- Commit 修改內容
- 修改過哪些檔案
- 修改了多少行
- 某個檔案在指定 Commit 的內容

---

### 基本查詢

| 指令 | 用途 |
|------|------|
| `git show` | 查看目前 `HEAD` 指向的 Commit |
| `git show HEAD` | 查看目前 HEAD 的 Commit |
| `git show HEAD~n` | 在線性歷史中，查看 HEAD 往前數第 n 個 Commit |
| `git show Commit-ID` | 查看指定 Commit |

---

### 查看 Commit 修改內容

| 指令 | 用途 | 列出的資訊 |
|------|------|------|
| `git show` | 查看 Commit 詳細內容 | Commit 基本資料與修改差異 |
| `git show --name-only` | 查看修改過哪些檔案 | Commit 基本資料 + 檔案名稱 |
| `git show --name-status` | 查看修改過的檔案及狀態 | Commit 基本資料 + 檔案名稱 + 變動狀態 |
| `git show --stat` | 查看修改過的檔案及增刪行數統計 | Commit 基本資料 + 檔案名稱 + 增刪統計 |
| `git show --word-diff` | 以文字為單位顯示修改差異 | 以文字標示新增與刪除內容 |
| `git show --no-patch` | 不顯示修改差異 | 只顯示 Commit 基本資料 |


---

### `<Commit ID> -- <檔案路徑>` 和 `<Commit ID>:<檔案路徑>`差異比較

| 比較項目 | `<Commit ID> -- <檔案路徑>` | `<Commit ID>:<檔案路徑>` |
|------|------|------|
| 用途 | 查看指定檔案在該 Commit 中的修改差異 | 查看該 Commit 當時，指定檔案的完整內容 |
| 是否顯示前後版本對比 | 是 | 否 |
| 顯示內容 | 該 Commit 對指定檔案做了哪些修改 | 該 Commit 當時特定檔案的完整內容 |
| 路徑基準 | 通常以目前所在目錄為基準 | 固定以 Git 專案根目錄為基準 |
| 符號作用 | `--` 是分隔 Commit 與檔案路徑 | `:` 是指定 Commit 裡面的檔案 |

### 速查表


| 指令 | 用途 | 列出的資訊 |
|------|------|------|
|`git show`| 查看目前 Commit 及其修改的內容 | Commit 基本資料與修改差異 |
|`git show HEAD~n`| 查看 HEAD 往前數第 n 個 Commit | Commit 基本資料與修改差異 |
|`git show Commit-ID`| 查看指定 Commit | Commit 基本資料與修改差異 |
|`git show --name-only`| 查看修改過哪些檔案 | Commit 基本資料 + 檔案名稱 |
|`git show --name-status`| 查看修改過的檔案及狀態 | Commit 基本資料 + 檔案名稱 + 變動狀態 |
|`git show --stat`| 查看修改過的檔案及增刪行數統計 | Commit 基本資料 + 檔案名稱 + 增刪統計 |
|`git show --word-diff`| 以文字為單位顯示修改差異 | 以文字標示新增與刪除內容 |
|`git show --no-patch`| 不顯示修改差異 | 只顯示 Commit 基本資料 |
|`git show Commit-ID -- 檔案路徑`| 查看指定檔案在該 Commit 中的修改差異 |該 Commit 對指定檔案做了哪些修改 |
|`git show Commit-ID:檔案路徑`| 查看該 Commit 當時，指定檔案的完整內容 |該 Commit 當時特定檔案的完整內容 |
