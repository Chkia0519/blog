`git show` 主要用來查看**指定 Commit 的詳細資訊**

除了可以查看 Commit 資訊之外，也可以查看：

- Commit 修改內容
- 修改過哪些檔案
- 修改了多少行
- 某個檔案在指定 Commit 的內容

---

### 基本查詢

| 指令 | 用途 |
|------|------|
| `git show` | 查看目前 `HEAD` 指向的 Commit |
| `git show HEAD` | 查看目前 HEAD 的 Commit |
| `git show HEAD~n` | 查看目前 HEAD 往前數第 n 個 Commit |
| `git show Commit-ID` | 查看指定 Commit |

---

### 查看 Commit 修改內容

| 指令 | 用途 |
|------|------|
| `git show` | 查看 Commit 詳細內容 |
| `git show --stat` | 查看修改檔案及增刪行數 |
